# Desafio do módulo [Fundamentos de HTML e CSS]

Consiste em desenvolver uma página web com informações sobre um determinado local turístico.

Nesta página será trabalhado:
- Estrutura HTML;
- Estilização com CSS;
- Fontes;
- Espaçamentos;
- Imagens;
- Listas não ordenadas;
- Alterações das cores dos textos;
- Alterações da espessura dos textos;
